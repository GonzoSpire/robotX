# ROBOTX

ПвЕ-роглайк про битвы роботов в духе Vampire Survivors. TypeScript + Three.js, без игрового движка. Веб + мобильные браузеры (PWA в планах).

## Текущее состояние (M0–M2 готово)

- **Забег 10 минут**: волны мобов трёх типов (гончая / спринтер / голем), рост сложности по времени, скачки каждые 45 секунд, **босс Ядро-Титан на 10-й минуте**.
- **7 видов оружия**: автопушка, лазерный резак, ракеты, орбитальные дроны, шокволна, огнемёт, мины. Каждое качается до 8 уровня.
- **8 пассивок** по 5 стаков: урон, скорость атаки, бег, HP, магнит, крит, опыт, площадь.
- **Левел-апы**: выбор 1 из 3 карточек с паузой (мышь/тап или клавиши 1-2-3).
- **Активные способности**: рывок (Space) и щит (E) с кулдаунами.
- **Двухслойные награды**: карточки внутри забега + скрап между забегами (сейв в localStorage).
- **Управление**: WASD/стрелки + плавающий тач-джойстик и кнопки на телефоне.
- **Рендер 2.5D**: процедурные 3D box-боты, камера сверху, всплывающие цифры урона, VFX.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

По локальной сети с телефона: `http://<ip-компьютера>:5173` (сервер слушает все интерфейсы).

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с HMR |
| `npm run build` | typecheck + продакшен-сборка в `dist/` |
| `npm run preview` | локальный просмотр сборки |
| `npm test` | vitest (логика симуляции, спавнер, карточки, каталог) |
| `npm run typecheck` | проверка типов |

## Структура

```
src/
  core/      — игровой цикл (fixed timestep 60 Гц), сидируемый RNG, сейвы
  content/   — каталоги контента: weapons, enemies, passives (баланс = код)
  run/       — симуляция забега: игрок, оружие, снаряды, ИИ, спавн-директор, карточки
  meta/      — (M3) инвентарь, крафт, энергобюджет — заготовка
  render/    — Three.js: сцены забега и ангара, процедурные боты
  ui/        — HUD и экраны (HTML/CSS поверх канваса)
  input/     — клавиатура + тач-джойстик
tests/       — vitest
```

## Дорожная карта

- **M3 — Ангар и конструктор**: шасси/реактор/оружея/модули, энерго-бюджет, редкости, сет-бонусы, крафт по чертежам, дерево пилота.
- **M4 — Полировка**: PWA (установка на телефон, офлайн), оптимизация сотен мобов (инстансинг), баланс, деплой.
- **Далее** — PvP-режимы.

## Отладка

В dev-режиме приложение доступно в консоли как `window.__robotx` (симуляция, сейв, принудительный старт забега).
