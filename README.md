# ROBOTX

ПвЕ-роглайк про битвы роботов в духе Vampire Survivors. TypeScript + Three.js, без игрового движка. Веб + мобильные браузеры (PWA в планах).

## Сетевой кооп (до 4 игроков)

Кнопка **СЕТЬ** в ангаре открывает лобби:
- **Создать лобби** — вы хост, появляется код комнаты (5 символов) и ссылка `?room=КОД`.
- **Подключиться по коду** — вводите код друга или открываете его ссылку (автоприсоединение).
- До 4 роботов; старт, когда все нажали «ГОТОВ». Хост запускает забег кнопкой **СТАРТ**.

Правила коопа:
- Все в одной арене, мобы бьют ближайшего, общий опыт и уровень команды.
- Скрап и чертежи засчитываются подобравшему; награды применяются к своему сейву.
- Левел-ап — карточки без паузы (очередь); погибший наблюдает за союзниками.
- Забег длится, пока жив хоть один робот; победа — убить Ядро-Титана.
- Отключение игрока — его бот погибает, забег продолжается.

Технически: хост-авторитарная схема поверх WebRTC (библиотека [PeerJS](https://peerjs.com), публичный сигнальный сервер + STUN). Хост считает симуляцию 60 Гц, клиенты шлют ввод и получают бинарные снапшоты ~20 Гц с интерполяцией; свой робот предсказывается локально. Свой сервер не нужен — работает на GitHub Pages. Ограничение: у редких «строгих» NAT прямое соединение может не установиться без TURN-сервера.

## Текущее состояние (M0–M3 готово)

**Ангар и конструктор робота**:
- **Слоты**: шасси + реактор + 2–4 оружейных слота + 2–5 модульных (зависит от шасси).
- **Энергобюджет**: реактор даёт энергию, оружие и модули потребляют — перегруз блокирует забег.
- **28 деталей**: 5 шасси, 4 реактора, 7 оружейных, 12 модулей; редкости обычная→легендарная.
- **Сет-бонусы** производителей: Вектор (урон), Криоген (скорость), Гелиос (опыт) — 2+ детали.
- **Крафт по чертежам** за скрап, разборка деталей обратно в скрап (40%).
- **Дерево пилота**: 6 узлов постоянных бонусов (HP, урон, скорость, подбор, опыт, скрап).

**Забег 10 минут**:
- Волны мобов трёх типов (гончая / спринтер / голем), рост сложности, скачки каждые 45 секунд, **босс Ядро-Титан на 10-й минуте**.
- **7 видов оружия** до 8 уровня, **8 пассивок** по 5 стаков, карточки левел-апа (1 из 3).
- **Активные способности**: рывок (Space) и щит (E).
- **Двухслойные награды**: карточки внутри забега + скрап и чертежи между забегами.
- Чертежи падают: 25% с големов, 100% с босса.

**Управление**: WASD/стрелки + плавающий тач-джойстик и кнопки на телефоне.

**Рендер 2.5D**: процедурные 3D box-боты, камера сверху, всплывающие цифры урона, VFX.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

По локальной сети с телефона: `http://<ip-компьютера>:5173` (сервер слушает все интерфейсы).

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с HMR |
| `npm run build` | typecheck + продакшен-сборка в `dist/` |
| `npm run preview` | локальный просмотр сборки |
| `npm test` | vitest (симуляция, мета-слой, крафт, лоадаут) |
| `npm run typecheck` | проверка типов |

## Структура

```
src/
  core/      — игровой цикл (fixed timestep 60 Гц), сидируемый RNG, сейвы (v2)
  content/   — каталоги боевого контента: weapons, enemies, passives
  meta/      — детали, лоадаут/энергобюджет, сеты, крафт, пилот
  run/       — симуляция забега: игроки, оружие, снаряды, ИИ, спавн-директор, карточки
  net/       — сетевой кооп: PeerJS-транспорт, лобби, протокол/снапшоты, хост/клиент
  render/    — Three.js: сцены забега и ангара, процедурные боты
  ui/        — ангар, лобби, HUD и экраны (HTML/CSS поверх канваса)
  input/     — клавиатура + тач-джойстик
tests/       — vitest
```

## Дорожная карта

- **M4 — Полировка**: PWA (установка на телефон, офлайн), оптимизация сотен мобов (инстансинг), баланс, деплой.
- **Далее** — PvP-режимы, больше деталей и оружий.

## Отладка

В dev-режиме приложение доступно в консоли как `window.__robotx` (симуляция, сейв, принудительный старт забега).
